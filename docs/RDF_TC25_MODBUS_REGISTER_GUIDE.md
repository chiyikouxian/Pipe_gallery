# RDF-TC25 应力传感器 Modbus 寄存器读取说明

## 1. 适用范围

本文用于通过 Modbus Poll 或 STM32/RT-Thread 读取 RDF-TC25 应力传感器配套 RDD-DH 力值显示控制仪的数据。

Modbus 通信对象实际是 RDD-DH 显示控制仪。RDF-TC25 通过应变桥信号连接到 RDD-DH，由 RDD-DH 完成采样、标定和 Modbus RTU 通信。

## 2. 当前现场通信参数

以下参数已经通过 Modbus Poll 实际通信验证，界面显示 `Err = 0`：

| 项目 | 当前值 | 说明 |
| --- | ---: | --- |
| 通信协议 | Modbus RTU | RS485 总线 |
| 串口 | COM12 | 以电脑实际识别的端口为准 |
| 从机地址 | 1 | Modbus Poll 中填写 `Slave ID = 1` |
| 波特率 | 9600 bit/s | 当前现场已验证 |
| 数据位 | 8 | 当前现场已验证 |
| 校验位 | None | 当前现场已验证 |
| 停止位 | 1 | 当前现场已验证 |
| 读功能码 | 03 | Read Holding Registers (4x) |

注意：厂家不同版本资料对默认停止位的描述存在差异，现场设备已经在 `9600-8-N-1` 下正常应答，因此调试和固件均应以设备当前参数为准。

## 3. 地址填写规则

厂家文档同时给出了 `4xxxx` 编号和从 0 开始的协议地址。例如：

| 厂家文档编号 | Modbus 协议地址 | Modbus Poll Address |
| ---: | ---: | ---: |
| 40001 | 0 | 0 |
| 40009 | 8 | 8 |
| 40031 | 30 | 30 |
| 40081 | 80 | 80 |

Modbus Poll 的 `Read/Write Definition` 窗口中应填写协议地址，不填写 `4xxxx` 编号，并且不要勾选 `PLC Addresses (Base 1)`。

实时力值的起始地址应填写 `80`，而不是 `40081`。

## 4. 推荐读取窗口

### 4.1 实时应力/力值

厂家明确说明“毛重即为实时变化的力值”，实际使用应优先读取毛重。

| Modbus Poll 参数 | 填写值 |
| --- | ---: |
| Slave ID | 1 |
| Function | 03 Read Holding Registers (4x) |
| Address | 80 |
| Quantity | 2 |
| Scan Rate | 1000 ms |
| PLC Addresses (Base 1) | 不勾选 |

寄存器含义：

| 从机地址 | 协议地址 | 文档编号 | 数据内容 | 类型 | 计算方法 |
| ---: | ---: | ---: | --- | --- | --- |
| 1 | 80 (`0x0050`) | 40081 | 毛重高 16 位 | 32 位有符号数的高字 | 与地址 81 合并 |
| 1 | 81 (`0x0051`) | 40082 | 毛重低 16 位 | 32 位有符号数的低字 | 与地址 80 合并 |

请求帧示例：

```text
01 03 00 50 00 02 C4 1A
```

Modbus Poll 显示格式可选择 `32-bit Signed` 或 `Long AB CD`。数据是高字在前、低字在后，不是 IEEE 754 浮点数，不要选择 `Float`，也不要交换两个 Word。

### 4.2 小数位和运行状态

| Modbus Poll 参数 | 填写值 |
| --- | ---: |
| Slave ID | 1 |
| Function | 03 Read Holding Registers (4x) |
| Address | 8 |
| Quantity | 1 |
| Scan Rate | 1000 ms |

| 从机地址 | 协议地址 | 文档编号 | 数据内容 | 类型 | 计算方法 |
| ---: | ---: | ---: | --- | --- | --- |
| 1 | 8 (`0x0008`) | 40009 | 模块状态 | 16 位无符号整数 | 小数位数为 `status & 0x0007` |

状态位定义：

| 位 | 0 | 1 |
| --- | --- | --- |
| Bit 11 | 未检测到峰值 | 检测到峰值 |
| Bit 10 | 未检测到谷值 | 检测到谷值 |
| Bit 9 | 正常 | 超载 |
| Bit 8 | 常规传感器 | 智能传感器 |
| Bit 7 | 非零点 | 零点 |
| Bit 6 | 正常 | 溢出 |
| Bit 5 | 稳定 | 不稳定 |
| Bit 4 | 开机未清零 | 开机已清零 |
| Bit 3 | 正号 | 负号 |
| Bit 2..0 | 小数位数，范围 0 至 7 | - |

### 4.3 显示单位

| Modbus Poll 参数 | 填写值 |
| --- | ---: |
| Slave ID | 1 |
| Function | 03 Read Holding Registers (4x) |
| Address | 104 |
| Quantity | 1 |

| 从机地址 | 协议地址 | 文档编号 | 数据内容 | 类型 | 返回值含义 |
| ---: | ---: | ---: | --- | --- | --- |
| 1 | 104 (`0x0068`) | 40105 | 重量/力值单位 | 16 位无符号整数 | `0` 无单位；`1` g；`2` kg；`3` t；`4` N |

该寄存器为读写寄存器。调试阶段只读取，不要在未确认仪表标定参数时写入。

## 5. 实际数值计算

### 5.1 合并两个寄存器

设：

```text
reg_high = 地址80的值
reg_low  = 地址81的值
```

先组合为 32 位无符号数据，再按 32 位有符号补码解释：

```c
uint32_t combined = ((uint32_t)reg_high << 16) | reg_low;
int32_t raw_value = (int32_t)combined;
```

等价数学表达：

```text
combined = reg_high * 65536 + reg_low

如果 combined < 2147483648：
    raw_value = combined
否则：
    raw_value = combined - 4294967296
```

### 5.2 应用小数点

从地址 8 读取模块状态：

```c
uint8_t decimal_places = status & 0x07;
double displayed_value = raw_value / pow(10.0, decimal_places);
```

不使用浮点库时可使用查表：

```c
static const uint32_t pow10_table[] =
{
    1U, 10U, 100U, 1000U, 10000U, 100000U, 1000000U, 10000000U
};
```

### 5.3 换算为 kN

先根据地址 104 判断单位：

| 单位代码 | 当前显示单位 | 换算为 kN |
| ---: | --- | --- |
| 4 | N | `kN = displayed_value / 1000` |
| 3 | t | 若按吨力标定，`kN = displayed_value * 9.80665` |
| 2 | kg | 若按千克力标定，`kN = displayed_value * 9.80665 / 1000` |
| 1 | g | 若按克力标定，`kN = displayed_value * 9.80665 / 1000000` |
| 0 | 无单位 | 不能直接换算，必须确认仪表标定单位 |

应力传感器用于力值测量时，建议将仪表单位设置为 `N`，这样转换为 kN 只需除以 1000，含义最明确。

## 6. 当前读取示例

Modbus Poll 当前读取结果：

```text
地址80（高16位）= 0
地址81（低16位）= 108
```

合并结果：

```text
combined = 0 * 65536 + 108
raw_value = 108
```

最终值取决于地址 8 返回的小数位：

| 地址 8 的低三位 | 小数位 | 实际显示值 |
| ---: | ---: | ---: |
| 0 | 0 | 108 |
| 1 | 1 | 10.8 |
| 2 | 2 | 1.08 |
| 3 | 3 | 0.108 |

例如地址 8 返回 `0x0802`：

```text
decimal_places = 0x0802 & 0x0007 = 2
displayed_value = 108 / 100 = 1.08
```

如果地址 104 返回 `4`，则单位为 N：

```text
force = 1.08 N
force = 0.00108 kN
```

高 16 位保持为 0 是正常现象。正数小于 65536 时通常只有低 16 位变化；数值超过 65535 或变为负数时，高 16 位才会发生明显变化。

## 7. 常用读取寄存器信息表

除特别说明外，以下寄存器均使用从机地址 `1` 和功能码 `03` 读取。

| 协议起始地址 | 十六进制 | 文档编号 | 数量 | 数据类型 | 内容 | 读取后的处理 |
| ---: | ---: | ---: | ---: | --- | --- | --- |
| 0 | `0x0000` | 40001 | 1 | `uint16` | 当前从机地址 | 数值范围 1 至 247 |
| 1 | `0x0001` | 40002 | 1 | `uint16` | 波特率代码 | 当前现场应对应 9600；只读检查，不要随意写入 |
| 2 | `0x0002` | 40003 | 1 | `uint16` | 数据帧格式 | `0x03`=8E1，`0x04`=8O1，`0x05`=8N1，`0x06`=8N2 |
| 3 | `0x0003` | 40004 | 1 | `uint16` | 协议类型 | `0x01` 表示 Modbus RTU |
| 6 | `0x0006` | 40007 | 1 | `uint16` | 固件版本 | 直接显示无符号整数 |
| 8 | `0x0008` | 40009 | 1 | `uint16` | 模块状态和小数位 | 小数位=`value & 0x07`；其余按状态位表解析 |
| 30 | `0x001E` | 40031 | 2 | `int32`，高字在前 | 测量值 | 两个寄存器合并后按补码解释，再应用小数位；厂家不建议作为实际使用值 |
| 44 | `0x002C` | 40045 | 2 | `int32`，高字在前 | 滤波后的原始 AD 内码 | 仅用于标定和诊断，不能直接当作 kN |
| 46 | `0x002E` | 40047 | 2 | `uint32`，高字在前 | 传感器灵敏度 | 返回值除以 10000，单位 mV/V；例如 20000 表示 2.0000 mV/V |
| 48 | `0x0030` | 40049 | 2 | `uint32`，高字在前 | 传感器量程 | 数值精度由仪表标定设置决定 |
| 80 | `0x0050` | 40081 | 2 | `int32`，高字在前 | 毛重，即实时力值 | 推荐值；合并、补码解释、应用小数位和单位 |
| 82 | `0x0052` | 40083 | 2 | `int32`，高字在前 | 净重 | `净重 = 毛重 - 皮重`，再应用小数位和单位 |
| 84 | `0x0054` | 40085 | 2 | `int32`，高字在前 | 皮重 | 合并后按补码解释，再应用小数位和单位 |
| 86 | `0x0056` | 40087 | 2 | `uint32`，高字在前 | 最大称量 | 合并后按无符号整数解释，再应用小数位和单位 |

| 293 | `0x0125` | 40294 | 2 | `int32`，高字在前 | 谷值 | 合并后按补码解释，再应用小数位和单位 |

说明：厂家文档指出地址 30 的“测量值”不能执行清零，实际使用应读取地址 80 的“毛重”。

## 8. 建议的 Modbus Poll 调试顺序

1. 读取地址 `0`、数量 `1`，确认返回值为当前从机地址 `1`。
2. 读取地址 `8`、数量 `1`，记录小数位、超载、溢出和稳定状态。
3. 读取地址 `104`、数量 `1`，确认当前显示单位。
4. 读取地址 `80`、数量 `2`，观察实时力值。
5. 对传感器施加和释放载荷，确认地址 80/81 的合并值随载荷连续变化。
6. 对比计算结果与 RDD-DH 面板显示，确认小数位和单位完全一致。
7. 调试期间确保 RS485 总线上只有一个主站，不要让 Modbus Poll 和 STM32 同时轮询。

## 9. 修改从机地址

RDD-DH 的系统配置上电后默认为锁定状态。修改模块地址必须使用功能码 `0x10`
（写多个保持寄存器），不能使用功能码 `0x06`。

将地址从 `1` 修改为 `3` 时，应在总线上只连接这一台 RDD-DH，并依次执行：

1. 向地址 `1` 的寄存器 `0x0005` 写入 `0x5AA5`，解锁系统配置。
2. 向地址 `1` 的寄存器 `0x0000` 写入 `0x0003`。
3. 使用地址 `3` 读取寄存器 `0x0000`，确认返回值为 `3`。
4. 向地址 `3` 的寄存器 `0x0005` 写入非 `0x5AA5` 值，重新锁定配置；重新上电也会恢复锁定状态。

厂家给出的解锁请求帧为：

```text
01 10 00 05 00 01 02 5A A5 5C DE
```

厂家给出的地址 `1` 修改为地址 `2` 示例帧为：

```text
01 10 00 00 00 01 02 00 02 27 91
```

生产固件已固定使用地址 `3`，不再提供修改地址的 MSH 命令。需要重新配置时应使用
独立 Modbus 工具，并确保总线上只有这一台 RDD-DH。

## 10. 设置单位为 N 并保留两位小数

设备已经通过功能码 `0x10` 将单位寄存器 `0x0068` 配置为 `4`（N），状态寄存器
`0x0008` 已确认小数位为 `2`。生产固件只读取这些配置，不再提供写配置的 MSH 命令。

## 11. 固件实现注意事项

当前工程中的旧应力传感器实现使用了以下假设：

```text
起始地址：0x0000
寄存器数量：2
换算方式：combined / 65535 * 400 kN
```

该假设与 RDF-TC25/RDD-DH 厂家协议不一致。正式固件应调整为：

```text
实时值起始地址：0x0050
寄存器数量：2
数据类型：int32_t，高16位在前
小数位地址：0x0008，decimal_places = status & 0x07
单位地址：0x0068
实际值：raw_value / 10^decimal_places
```

不应使用 `combined / 65535 * 400` 作为 RDF-TC25 的力值换算公式。
