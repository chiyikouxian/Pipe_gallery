1. 修改 WiFi 配置
===============================================================================

打开文件: applications/huaweiCloudApp.h

修改第 26-27 行:
#define HW_WIFI_SSID           "YOUR_WIFI_SSID"      // 改为你的WiFi名称
#define HW_WIFI_PASSWORD       "YOUR_WIFI_PASSWORD"  // 改为你的WiFi密码

===============================================================================
2. 华为云设备配置 (已完成)
===============================================================================

设备ID: 6abf5210e094d61592745069_1776006881
接入地址: 2f49ff4f87.st1.iotda-device.cn-east-3.myhuaweicloud.com
端口: 1883 (MQTT非加密)

===============================================================================
3. 华为云服务ID配置 (需要确认)
===============================================================================

当前代码中使用的服务ID: "PipeMonitor"

请在华为云控制台确认:
- 进入 产品 -> 你的产品 -> 功能定义
- 查看 服务ID 是否为 "PipeMonitor"
- 如果不是，请修改 huaweiCloudApp.h 第 43 行的 SERVICE_ID_SENSOR 为实际的服务ID

===============================================================================
4. 上报的数据属性 (共20个)
===============================================================================

1. ch0, ch1, ch3, ch4, ch5       - 火焰传感器ADC值 (int, 0-65535)
2. methane_ppm, methane_lel      - 甲烷浓度 (int, ppm和LEL%)
3. voltage_a, voltage_b, voltage_c - 三相电压 (decimal, V)
4. current_a, current_b, current_c - 三相电流 (decimal, A)
5. flow                          - 水流量 (decimal, m³/h)
6. temperature, humidity         - 温湿度 (decimal, ℃和%RH)
7. o2                           - 氧气浓度 (decimal, %)
8. displacement                 - 位移 (decimal, mm, 0-2000)
9. stress                       - 应力 (decimal, N)
10. flame                       - 火焰状态 (int, 0或1)

===============================================================================
5. 编译和烧录
===============================================================================

1. 修改 WiFi 配置后，编译项目:
   scons

2. 烧录到 STM32H743:
   使用 STM32CubeProgrammer 或 Keil/IAR 下载 rt-thread.elf

3. 查看串口日志:
   波特率: 115200
   预期输出:
   [HuaweiCloud] Huawei Cloud thread started.
   [HuaweiCloud] Step 0: Check ESP8266...
   [HuaweiCloud] Step 1: Set WiFi mode...
   [HuaweiCloud] Step 2: Connect to WiFi...
   [HuaweiCloud] WiFi connected!
   [HuaweiCloud] MQTT connected! Device is online.
   [HuaweiCloud] All data reported OK

===============================================================================
6. 华为云控制台查看数据
===============================================================================

1. 登录华为云物联网平台
2. 进入 设备 -> 管廊节点
3. 点击 设备详情
4. 查看 数据上报 或 实时数据
5. 应该能看到20个属性的实时数据

===============================================================================
7. 上报周期配置
===============================================================================

当前上报周期: 3秒

修改周期: huaweiCloudApp.h 第 46 行
#define CLOUD_REPORT_INTERVAL   3000    /* 改为你需要的毫秒数 */

建议:
- 测试阶段: 3000ms (3秒)
- 生产环境: 10000ms (10秒) 或更长，节省流量

===============================================================================
8. 故障排查
===============================================================================

问题1: ESP8266不响应
解决: 检查 UART4 连接 (PA11/PA12)，ESP8266供电

问题2: WiFi连接失败
解决: 检查SSID和密码，确认WiFi 2.4GHz频段

问题3: MQTT连接失败
解决: 确认华为云设备在线，检查设备密钥是否正确

问题4: 数据上报失败
解决: 确认服务ID匹配，检查JSON格式，查看华为云日志
